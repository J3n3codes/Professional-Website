# Professional Portfolio

A portfolio showcasing research, data science, quantitative methods, teaching, writing, and interdisciplinary work.

**GitHub Pages URL:** https://j3n3codes.github.io/Professional-Website/

## Files

- `index.html` — main one-page portfolio and navigation.
- `style.css` — shared responsive styles and coursework cards.
- `script.js` — language preference, timeline interaction, and course-card behavior.
- `en/about.html` — background and selected experience.
- `en/contact.html` — contact and collaboration information.
- `en/dates.html` — publications and manuscript-status page.
- `images/portfolio.jpeg` — optional portrait/photo; add your image using this exact filename, or update the image path in `index.html`.

## Deploy with GitHub Pages

1. Upload the contents of this folder to the root of the `Professional-Website` repository (the folder should contain `index.html` directly, not another nested `Professional-Website` folder).
2. Commit and push the changes to the repository's publishing branch, usually `main`.
3. In GitHub, open **Settings → Pages** and confirm the source branch and root folder.
4. Visit the GitHub Pages URL above after the deployment finishes.

The site is static HTML, CSS, and JavaScript; it does not require a build step or package installation.

## Before publishing

See [`SUGGESTIONS.md`](SUGGESTIONS.md) for the correction log and publication checklist. In particular, verify dates and course titles against official records, add only shareable document links, confirm contact details before making them public, and distinguish completed education from admission offers.

The `noindex, nofollow` meta tag asks compliant search engines not to index pages. It does **not** restrict access: anyone with the URL may view the site. Do not upload confidential, identifiable, or restricted research materials.


## Additional portfolio sections

The homepage includes education/admissions and awards, volunteering/community work, and mentors/intellectual influences. It also includes HTML placeholders for a thesis, writing sample, teaching-concept video, and research-presentation video. Replace the placeholder `href="#"` values with the intended public URLs before publishing.
